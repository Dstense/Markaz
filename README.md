# Markaz Restaurant — Premium Website

A responsive, GitHub Pages-ready restaurant website for Markaz Restaurant, Jogeshwari West, Mumbai.

## Included
- Cinematic full-screen hero
- Editorial parchment visual system
- Signature dish marquee
- Restaurant story and facts
- Menu showcase with real menu-category direction
- Review/rating section
- Address, hours and contact
- Google Maps directions
- Zomato menu/order links
- Mobile navigation and sticky action bar
- Reduced-motion support

## Publish
Upload `index.html`, `style.css`, `script.js` and this README to a GitHub repository, then enable GitHub Pages from the `main` branch root.

## Before publishing
Confirm the phone number, menu, prices, hours and ordering details with the restaurant, since listings can change.
