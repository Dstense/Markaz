# Markaz Restaurant — Premium Website

A responsive, GitHub Pages-ready restaurant website for Markaz Restaurant, Jogeshwari West, Mumbai.

## Included
- Cinematic full-screen hero
- Editorial parchment visual system
- Signature dish marquee
- Restaurant story and facts
- Signature menu highlights with public online-listing prices and a clear price disclaimer
- Restaurant photo gallery using images from public listing galleries
- Direct ordering links for Zomato and Swiggy
- Updated public listing address and phone number
- Google Maps directions and fixed mobile quick actions
- Review/rating section
- Address, hours and contact
- Google Maps directions
- Zomato and Swiggy menu/order links
- Mobile navigation and sticky action bar
- Reduced-motion support

## Publish
Upload `index.html`, `style.css`, `script.js` and this README to a GitHub repository, then enable GitHub Pages from the `main` branch root.

## Before publishing
Displayed prices are sampled from Markaz’s public Zomato online menu and can change or differ from other delivery apps. Check the linked live menu before ordering. Contact details, hours and the address are based on the public restaurant listing and should be reconfirmed with the restaurant. Photos in the gallery are hotlinked from public restaurant/delivery listings; replace with restaurant-owned originals when available.
